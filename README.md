## Über das Projekt

Pokémon Gamma Emerald ist inzwischen weitgehend auf Deutsch spielbar. Die Übersetzung befindet sich weiterhin im Feinschliff, daher können noch englische Texte, Übersetzungsfehler oder kleinere Darstellungsprobleme auftreten.

## Fehler gefunden?

Wir freuen uns über jeden Hinweis und jeden Fehlerbericht. Bitte beschreibe möglichst kurz:

- wo der Fehler aufgetreten ist,
- welcher Text oder welche Anzeige betroffen ist,
- und füge wenn möglich einen Screenshot hinzu.

[**Fehler melden →**](https://github.com/FadeyMods/Pokemon-Gamma-Emerald-Deutsch/issues/new/choose)
